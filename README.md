# Cafe Latte

A responsive, interactive coffee shop web application built with HTML5, CSS3, and vanilla JavaScript.

## Features
- **Interactive Menu Filtering & Search:** Filter menu items by category and search dynamically in real time (`app.js`).
- **Responsive Navigation & Accessibility:** Accessible mobile navigation drawer with keyboard (`Escape`) and click-outside support.
- **Scroll Reveal & Dynamic UI:** Smooth section reveal animations (respecting reduced-motion preferences) and automatic dynamic footer year updates.
- **Responsive Grid & Flexbox Layout:** Clean, structured layout across desktop and mobile viewports.

## Tech Stack
- **Frontend:** HTML5, CSS3 (Grid & Flexbox), JavaScript (ES6+)
